# Autonomous Taxi Management System

A Java application for managing an autonomous taxi service in an urban environment, developed as part of a university programming assignment.

## Overview

The project focuses on designing a system for managing driverless taxis in a city. It explores object-oriented programming principles and the development of software components for an autonomous transportation service.

## Technologies

- Java
- Object-Oriented Programming (OOP)
